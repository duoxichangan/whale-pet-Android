# 动作分类

106 个动作完整分为 21 种食物、24 种玩乐、61 个自发或手势触发动作，没有遗漏，也没有把喂食/玩乐放入随机池。

“自发动作”默认展示全部 61 个；日常筛选包含 56 个，休息筛选包含 8 个，二者共享基础待机、悠闲哼歌、摇扇纳凉 3 个动作。这里也展示轻触与拖动等系统触发动作，逐行标明触发方式，不把所有条目都视作定时随机动作。

日常随机池 45 个，休息随机池 7 个。2.2.0 起，符合精力与自在走动条件时，60% 跑步，其余 40% 在 45 个日常动作及另两种走动中等概率抽取；关闭走动或低精力时仅在日常池等概率抽取。休息池 7 个等概率抽取。允许连续重复，不再固定交替。睡眠、打哈欠、伸懒腰、发呆只在休息时随机；“打瞌睡被惊醒”作为休息时的轻触回应，不在睡眠中无故播放；拖拽悬空仅随拖动触发。日常点击有 6 种回应，休息点击使用 3 种较轻的回应。食物和玩乐的原数值及饱食/心情/精力机制不变。

原角色文件与原 action-policy.json 保持原始校验值；本次模式和触发调整在 native-action-behavior.json 中单独声明。
